# BookLog

Biblioteca pessoal com cara de rede social: o usuário cadastra livros, avalia, escreve resenhas curtas e acompanha o status de leitura (quero ler, lendo, lido). Um catálogo de descoberta usará a Open Library API.

## Etapa 1: estrutura HTML

- `index.html`: Minha estante (pesquisa, filtro, ordenação, tabela e livro selecionado)
- `pages/cadastro.html`: formulário de cadastro (e edição) de livro
- `pages/livro.html`: detalhes de um livro
- `pages/descobrir.html`: busca no catálogo
- `pages/perfil.html`: dados e estatísticas do usuário
- `pages/login.html`: login simples

Os dados são fictícios e estáticos; JavaScript e CSS entram nas próximas etapas.
